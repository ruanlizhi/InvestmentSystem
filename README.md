# InvestmentSystem

本地投资研究与决策工作台：投资原则 → 标的分析 → 观察预案 → 事前决策 → 实际操作 → 复盘。

版本：0.1.0。首版代码已实现，自动测试、静态检查与构建通过；真实浏览器视觉验收待完成。早期预览，采用 [MIT 许可证](LICENSE)；未部署公开网站。

## 启动公开版

需要 Bun 1.3.11+。

```bash
bun install --frozen-lockfile
bun run build
bun run demo
```

默认本机地址为 `http://localhost:4318`。公开版使用经授权的固定快照；美股账户历史为明确标注的虚构示例。程序不会读取私人工作区，后续私人更新不会自动公开。

## 私人使用

```bash
bun run cli init --workspace <仓库外工作区>
bun run start --workspace <仓库外工作区>
```

默认本机地址为 `http://localhost:4317`。已有数据无需重复 init。代码与私人内容分离，私人资料、配置、批次和备份均放在仓库之外。

## 已实现

- 六个只读页面、搜索筛选、标的详情、版本与关联追溯、讨论摘要。
- CLI 维护共享持久记录：读取、检索、批次更新和备份恢复。
- 原则及研究版本化，引用精确到版本；直接或间接依据变更提示复核。
- 账户期初、资金流、实际成交核算；决策与成交分开，保存资金持仓截面。
- 独立公开快照、本机访问、固定静态资源清单、修订冲突保护。

不包含自动交易、实时行情、自动研究、券商同步、多用户远程服务、复杂收益计算或压力测试。界面由 DOM 单元测试覆盖基本行为，尚不能据此宣称真实浏览器外观通过。

## 开发验证

```bash
bun test
bunx tsc --noEmit
bun run build
bun run check:release
```

`check:release` 仅检查显式候选文件，不代表授权发布。公开展示仅使用明确授权的内容快照；未授权的真实资料和个人助手配置不得进入仓库或发布包。
