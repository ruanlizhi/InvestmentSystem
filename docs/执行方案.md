# 第一版执行方案

状态：代码和自动测试完成，真实浏览器验收待完成，见[首版验收记录](首版验收记录.md)。目标是交付可在本机运行、可持久保存、可由对话工具维护的投资工作台。

## 交付范围

1. 六个页面：总览、原则、标的、预案、资金持仓、操作复盘。支持搜索、关联跳转、版本历史与讨论摘要。
2. 一个共享数据入口：CLI 写入，网页读取同一工作区；刷新获取最新记录。页面不承担大量表单录入。
3. 版本化原则、研究、资料、预案、决策及复盘。关键引用精确到版本；新版本提示旧引用待复核。
4. 账户期初、资金流与实际成交；决策不改变持仓。操作保存前后账户截面，缺失事前讨论明确显示。
5. 软件与数据目录隔离；演示固定使用虚构记录；真实记录不进入代码或构建目录。

## 实现选择

Bun 1.3.11+、TypeScript、原生 DOM/CSS。无外部运行依赖、字体、分析脚本或模型请求。服务仅监听 127.0.0.1，使用固定静态文件清单，不提供任意文件读取和网页写接口。

工作区使用带格式版本的 JSON 文档，存放不可变记录版本及审计信息。CLI 使用独占写锁、修订号检查、校验、旧版备份和临时文件原子替换。备份保留在工作区；恢复时保留恢复前文件。首版只支持格式版本 1，遇到未来格式拒绝读写，不猜测迁移。

记录类型为 principle、asset、evidence、plan、decision、account、flow、trade、review。所有记录保留来源、内容身份、日期及录入时间；原文路径只作引用，不由服务端自动读取。

财务按账户币种独立核算，不跨币种求和。金额使用最小货币单位整数，数量允许小数。账户期初、资金流、成交按账户时间顺序追加，拒绝超额卖出、已知现金不足及重复 ID；历史更正暂需在副本核对后重建工作区，不静默修改成交。

## 实施顺序与验收

|阶段|交付|验证|
|---|---|---|
|数据闭环|记录校验、版本引用、持久化、备份与恢复|跨进程读取、并发冲突、损坏输入、旧版可追溯|
|财务与决策|期初、资金流、成交、事前/事后截面|独立算例，买卖/费用/未知余额/禁止意向入账|
|页面|六页及标的详情、筛选、关联、摘要|构建检查；真实浏览器导航、交互与截图|
|公私隔离|独立演示、私有启动参数、发布文件清单|服务路径攻击测试，发布包内容检查|
|交付|启动脚本、CLI 文档、数据格式与实测结果|从干净演示工作区完成一条完整操作链|

## 保留边界

不自动下单，不把讨论认定为成交；不推断真实资金、持仓或买卖阈值。资料不自动送外部模型。首版不包含实时行情、自动证伪判断、券商同步、多用户远程部署、复杂收益率及压力测试、方法自动评测。网页中缺项明确显示待补充。

界面采用阅读工作台：浅色底、墨绿导航、衬线标题、系统中文字体和等宽数字，短淡入并尊重减少动态偏好。资产与待复核事项优先，详细依据按需展开。

## 发布与验证说明

本次仅本地实现，不推送或公开发布。许可证仍待确定。公开候选文件独立检查，不携带个人 ISA 或私人资料。正式外部模型评审未开展：项目不允许外发私人材料，当前也没有已配置路由的 Git 工程；通过本地测试和代码复核验证。

浏览器验收必须使用当前环境允许的真实浏览器工具；工具不可用时明确记录未完成的视觉验收，不用 HTTP 成功冒充页面验收。

技术接口参考：[Bun HTTP server](https://bun.sh/docs/runtime/http/server)、[Bun bundler](https://bun.sh/docs/bundler)。实际兼容性以本地测试为准。
