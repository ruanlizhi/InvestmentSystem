# 数据与发布边界

状态：文档分拣及首版模式隔离、工作区路径检查、固定发布候选扫描已实现。当前支持格式版本 1 的备份恢复，未来格式迁移尚未实现。真实浏览器验收待完成。

## 归属

- 软件目录：通用代码、通用说明、空白模板、明确标记的虚构测试示例，以及本次明确授权的公开内容快照。
- 私人工作区：个人原则、研究、预案、资金持仓、操作、讨论、配置、索引和备份。
- 原始资料库：文章、日记及附件，未经授权不改写或复制全文。

混合文档完整保留在私人工作区；通用说明重新撰写，不直接公开个人方案及其历史。私人工作区必须位于软件仓库之外。

## 共同更新

维护一套软件，私人内容通过本地配置接入。功能更新修改软件；个人判断更新修改私人记录。未来数据格式升级需要版本号、备份、迁移验证和恢复路径，不能因更新软件覆盖私人数据。

## 发布范围

公开候选由 scripts/check-release.ts 明确列出：通用文档、代码、开发依赖清单、虚构测试及构建资源；私人工作区不在其中。当前清单不等于发布授权。后续新增文件逐项审查，不将整个目录默认视为可发布。

首次发布前确认许可证、代码与材料权利、仓库历史及实际发布包。公开展示使用经授权的固定快照，自动测试继续使用虚构资料，公开入口不接入私人目录；日志、缓存、打包文件也需要检查。忽略规则只是辅助措施，不是访问控制，也不会清除已经提交的历史内容。
