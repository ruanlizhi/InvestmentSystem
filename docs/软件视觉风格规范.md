# 深橄榄与暖杏：软件视觉风格规范

版本 1.0 · 2026-10-14

## 用途

从“人生导航”的 app/globals.css、app/NavigationIcon.tsx、src/audience.css 提炼，供不同业务的软件网页复用。只定义视觉语言，不规定页面布局、导航位置、功能、内容或流程。依据为源码，尚未核对当前浏览器画面。

## 风格基调

沉静、温暖、克制，带有中文阅读的书卷感。深橄榄底色、暖杏强调、米白文字；平整哑光，以细微明暗、细线和留白建立层次。“哑光”是观感，不要求添加纸纹或噪点。

## 为跨项目复用补充的规则

以下是规范化建议，不声称原工程已经全面实现。

### 留白节奏

采用 4、8、12、16、24、32、40、48px 间距尺度；同类元素内边距一致，组内紧凑、组间舒展。允许按用途选紧凑或舒适密度。此处规定疏密关系，不规定列数、导航方向或容器宽度。

### 视觉层级与强调比例

通过字号、字重、明暗、留白表达主次。深色表面占主体，暖杏集中用于少量重点。避免所有元素同时使用大标题、实色底和粗边框。哪些业务信息重要由各项目决定。

### 阅读尺度

正文建议 15–16px，辅助文字 13–14px，阅读行高 1.6–1.8。原工程部分 10–12px 小字不作为通用默认。展示标题保留宋体气质，操作标签、表格、数字优先保证清晰。

### 图标与装饰语言

常用图标显示尺寸 18–24px，维持同一笔画体系。装饰以少量细线、简洁几何、小色块为主；避免混用彩色实心图标、表情符号和细线图标。插画如需使用，应低饱和、克制，题材不属于本规范。

### 材质与空间感

默认 1px 边框和无阴影表面。避免厚重投影、浮雕、立体高光、霓虹光晕、大面积玻璃效果和强渐变。需要区分浮层时，仍优先沿用同一色系与清楚边界。

### 动效与反馈节奏

常规反馈建议 120–200ms，以颜色和透明度变化为主。避免弹跳、持续闪烁和大幅缩放。键盘焦点需清楚；悬停、选中、焦点、禁用可区分；减少动效设置有效。禁用功能必须实际不可操作。

### 状态与跨页面一致性

加载、空白、错误等状态沿用同一视觉语言。状态色的业务含义单独定义，并配文字或图标。图表可以继承色板、细线、排印，图表类型和数据组织不在本规范范围内。不同屏幕保持共同风格，不固定同一布局。

### 可读性底线

柔和不能以看不清为代价。实现时检查实际文字、背景、焦点和必要控件边界的辨识度；不能因为采用色板就宣称无障碍验收通过。重要信息不能仅靠颜色或极低透明度表达。

## 验收问题

- 主色关系是否仍然清楚，强调色是否过多？
- 字体、图标、线条、圆角、状态反馈是否统一？
- 留白与强调是否有一致节奏？
- 是否为了柔和牺牲文字、控件边界或焦点的辨识？
- 是否错误地把固定导航位置、卡片数量、业务内容或时间组织方式当作风格要求？

此规范不代表现有投资软件已经应用此风格，也不代表完成浏览器视觉验收。
