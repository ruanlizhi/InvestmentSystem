# 产品说明

状态：0.1.0 已实现核心记录闭环，自动验收通过；真实浏览器验收待完成。详见[首版验收记录](首版验收记录.md)。

## 目的

支持投资研究、事前准备、操作记录和事后验证。使用者定义自己的投资原则，软件提供关联、检索和历史追溯能力，不内置个人持仓或特定投资者的观点。

## 内容关系

投资原则 → 标的分析 → 观察与预案 → 事前决策 → 实际操作 → 复盘。关键分析引用原则版本，操作引用当时有效预案；资金与持仓为决策提供有日期的上下文。

## 页面草案

|页面|用途|
|---|---|
|总览|资金摘要、近期变化与待复核事项|
|投资原则|方法、适用边界、引用案例和修订历史|
|标的档案|分析、支持证据、反证、来源及未知项|
|观察与预案|观察内容、逻辑失效、买卖条件和准备事项|
|资金与持仓|带币种和日期的资金、持仓、资金流|
|操作与复盘|事前依据、实际执行、偏差及后续验证|

首版采用六页分组、Bun + TypeScript；视觉与真实浏览器交互仍待验收。

## 输入与记录

允许通过授权的对话工具整理内容，页面以查看、检索、比较和追溯为主。对话与页面应读取同一份持久记录；聊天本身不是数据库。候选想法、有效原则、操作意向和已成交记录分别保存。

原始文章保留来源；研究卡片记录发表日期、数据时期、定位、观点与核验状态。关联候选不自动成为已确认事实。

## 边界

缺失金额不等于零，未监测不等于未触发。修订不覆盖历史依据，事后信息不冒充事前证据。实际交易由使用者自行决定并执行，当前不设计自动下单。

## 首版范围

首版贯通原则、分析、预案、基础资金持仓、事前决策、实际操作及复盘。高级压力测试、自动采集和复杂收益计算后续扩展；核心功能已实现；高级能力保留后续扩展。

## 关联与版本

关键分析引用原则版本；预案记录观察内容、逻辑失效、买入、卖出及准备事项。讨论、本人决定和成交分别记录，引用当时有效的预案与资金持仓截面。无事前讨论的实际操作如实标记缺失，不补造计划；意向不改变实际持仓。等待也属于可回看的决策。

复盘分别核对原判断、执行偏差及结果。原则变化提示相关分析和预案复核，旧版本仍可定位。同一记录在不同页面展示，不重复维护。

## 页面细化建议

总览优先展示资产日期、待处理事项与近期变化。标的详情建议分为逻辑与分析、观察与预案、资料与想法、决策与历史；操作详情按事前、执行、事后三段展开。分析关联原则，原则可反查使用记录。

搜索、筛选、原文定位和版本比较优先于大量输入表单；可复制讨论摘要以衔接授权对话工具。首版采用仓库外版本化 JSON、CLI 批次更新和网页手动刷新；界面后续按实际使用反馈调整。

## 首版验收方向

- 从一条实际操作追溯预案、决策、资金截面、证据和原则版本。
- 保存后重新打开页面或切换对话仍能取得同一记录。
- 缺项、观点冲突、尚未成交及未完成事前讨论可明确区分。
- 演示数据与私人数据独立，升级前有可恢复备份。

公私数据及共同更新要求见[数据与发布边界](数据与发布边界.md)。
